### Valores inseridos no seed

## COMO USAR

### Adicionar produto novo (admin)
1. Acesse `/admin-loja/produtos/novo`
2. Selecione tipo: Mercado Livre (Afiliado) ou Estoque Próprio (Físico)
3. Para ML: cole o link e clique em "Extrair Dados" (preenche nome, preço, imagem automaticamente)
4. Preencha nome, categoria, preço (LOCAL_STOCK) ou link (AFFILIATE_ML)
5. Clique em "Salvar Produto" → redireciona para lista

### Editar produto (admin)
1. Acesse `/admin-loja/produtos/[id]`
2. Edite os campos (nome, categoria, preço, link, estoque)
3. Para LOCAL_STOCK: ajuste estoque na seção "Estoque"
4. Para AFFILIATE_ML: ajuste o link de afiliado na seção "Link do Mercado Livre"
5. Clique em "Salvar Produto" → redireciona para lista

### Seed futuro via API
```
GET /api/seed/mercadolivre
```
Busca produtos do Mercado Livre e insere no Supabase. Requer `NEXT_PUBLIC_SUPABASE_URL` e `SUPABASE_SERVICE_ROLE_KEY` configuradas no ambiente do servidor.

### Adicionar colunas extras (migration)
Rode no SQL Editor do Supabase:
```sql
ALTER TABLE public.products
  ADD COLUMN IF NOT EXISTS featured boolean NOT NULL DEFAULT false;
ALTER TABLE public.products
  ADD COLUMN IF NOT EXISTS tagline text NULL;
ALTER TABLE public.products
  ADD COLUMN IF NOT EXISTS rating numeric(3,1) NULL;
ALTER TABLE public.products
  ADD COLUMN IF NOT EXISTS reviews integer NULL DEFAULT 0;
```

Ou use o script: `scripts/migrate-products-columns.sql`
